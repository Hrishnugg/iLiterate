⟶ HTTP ⟵
API Routes (Next.js Server)

GET /api/progress

  • Returns user's reading_level, vocabulary_level, XP
  • Reads user_skill_levels

GET /api/lesson/history

  • Params: limit, offset, status
  • Returns lessons list + pagination + stats
  • Reads lesson_sessions

GET /api/lesson/[id]

  • Full lesson detail (body, vocab, quiz, scores)
  • Reads lesson_sessions

POST /api/lesson/generate

  • Body: { topic, length, useSuggestedTopic }
  • Calls OpenAI gpt-4o-mini to generate lesson
  • Reads profiles + user_skill_levels
  • Inserts into lesson_sessions (status: reading)

POST /api/lesson/[id]/complete-reading

  • Calls OpenAI to generate 4-6 quiz questions
  • Updates lesson_sessions → status: quiz

POST /api/lesson/[id]/submit

  • Body: { answers: { q1: "...", q2: "..." } }
  • Grades quiz (string match)
  • Calculates XP: floor(score/max × 50) + perfect bonus
  • Level adj: ≥80% → +1, <50% → −1, else → 0
  • Updates lesson_sessions → status: completed
  • Updates user_skill_levels → XP & level

POST /api/progress/downgrade

  • Drops all skills one CEFR tier, resets XP to 0
  • Optionally deletes in-progress lesson_sessions
  • Updates user_skill_levels

Scoring & Progression Logic

XP Calculation

  • Base XP = floor(score / maxScore × 50)
  • Perfect bonus = +10 XP (if 100%)
  • Auto level-up at 100 XP (resets to 0)
  • Max level: 20

Level Adjustment

  • ≥ 80% → +1 (harder next time)
  • 50–79% → 0 (same level)
  • < 50% → −1 (easier next time)

Quiz Questions

  • Short lesson → 4 questions
  • Medium lesson → 5 questions
  • Long lesson → 6 questions
  • Types: MCQ + fill-in-blank
RLS (Row Level Security) enforced on all tables — users can only access their own data
